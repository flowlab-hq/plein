# ArchiMate colours and icons

The Mac app (and any caller of `renderViewpointSvg` / `browseNamedView`) paints elements from a **shared style map** in [`src/archimate-style.ts`](../src/archimate-style.ts). The DSL `styles` block is still ignored — custom themes and Open Exchange styling are out of scope.

The [ArchiMate specification](https://www.opengroup.org/archimate-forum/archimate-overview) does not assign formal semantics to colour. Plein follows the **common convention** used by Archi’s inbuilt defaults (`AbstractArchimateElementUIProvider`) and the coloured example models in the spec:

| Layer | Fill | Stroke | Typical types |
| --- | --- | --- | --- |
| Strategy | `#F5DEAA` peach | `#C4A574` | `resource`, `capability`, `value-stream`, `course-of-action` |
| Motivation | `#CCCCFF` purple | `#7A7AB8` | `stakeholder`, `driver`, `goal`, `requirement`, … |
| Business | `#FFFFB5` yellow | `#C4C46A` | `business-actor`, `business-process`, `business-service`, … |
| Application | `#B5FFFF` cyan | `#5AA3A3` | `application-component`, `application-service`, `data-object`, … |
| Technology | `#C9E7B7` green | `#6F9A5A` | `node`, `device`, `artifact`, `technology-*`, … |
| Physical | `#C9E7B7` green (same as technology) | `#6F9A5A` | `equipment`, `facility`, `distribution-network`, `material` |
| Implementation and migration | `#FFE0E0` pink | `#C47A7A` | `work-package`, `deliverable`, `plateau`, `gap`, `implementation-event` |
| Composite (parser extra) | `#F2F2F7` gray | `#8E8E93` | `grouping`, `location` |
| Unknown / unsupported | `#F5F5F7` gray | `#8E8E93` | anything not in the catalogue (safe default) |

Physical shares technology green on purpose (Archi does the same). Distinguish those boxes by glyph and keyword, not hue.

Element keywords are the camelCase catalogue names from [`src/keywords.ts`](../src/keywords.ts) / [the language reference](plein-dsl-archimate-4.md). Unknown keywords never reach the renderer from `plein check` (they fail parse); `styleForElement` still returns the unknown default so a future caller cannot paint an unstyled box.

## Type glyphs

Each box keeps the rounded-rect chrome and gains a **16×16 glyph** in the top-right. These are simplified recognizers, not full ArchiMate figures (process-as-arrow, service-as-oval figure, and so on are out of scope).

| Glyph id | Shape (schematic) | Used by |
| --- | --- | --- |
| `actor` | stick figure | `businessActor`, `stakeholder` |
| `role` | arch / mask | `businessRole` |
| `collaboration` | overlapping circles | `*Collaboration` |
| `interface` | lollipop | `*Interface` |
| `process` | arrow | `*Process` |
| `function` | indented chevron | `*Function`, `capability` |
| `interaction` | overlapping rounded | `*Interaction` |
| `event` | pentagon | `*Event`, `implementationEvent` |
| `service` | ellipse | `*Service` |
| `object` | rectangle | `businessObject`, `dataObject`, `material` |
| `contract` | rectangle + rules | `contract` |
| `representation` | wavy document | `representation` |
| `product` | box + lid | `product` |
| `component` | UML component | `applicationComponent` |
| `node` | cube | `node` |
| `device` | monitor | `device` |
| `systemSoftware` | stacked slabs | `systemSoftware` |
| `path` | polyline | `path` |
| `network` | hub and spokes | `communicationNetwork`, `distributionNetwork` |
| `equipment` | machine | `equipment` |
| `facility` | building | `facility` |
| `resource` | crossed box | `resource` |
| `valueStream` | wide chevron | `valueStream` |
| `courseOfAction` | arrow to target | `courseOfAction` |
| `driver` | wheel | `driver` |
| `assessment` | gauge | `assessment` |
| `goal` | concentric target | `goal` |
| `outcome` | circle + check | `outcome` |
| `principle` | diamond + dot | `principle` |
| `requirement` | document + bar | `requirement` |
| `constraint` | requirement + slash | `constraint` |
| `meaning` | quotes | `meaning` |
| `value` | diamond | `value` |
| `workPackage` | chevron bar | `workPackage` |
| `deliverable` | package | `deliverable` |
| `plateau` | rectangle + midline | `plateau` |
| `gap` | offset squares | `gap` |
| `grouping` | dashed square (box also dashed) | `grouping` |
| `location` | map pin | `location` |
| `artifact` | folded document | `artifact` |
| `unknown` | rounded square + `?` | unsupported types |

Every catalogue keyword has a glyph. Shared glyphs (stakeholder→actor, capability→function, material→object, networks→`network`) are intentional shortcuts, not missing types.
